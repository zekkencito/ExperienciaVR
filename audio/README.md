# Carpeta de Audio

Coloca aquí tus archivos de audio para la experiencia VR.

## Archivos Requeridos:

1. **ambient.mp3** - Música de fondo ambiental (espacial/relajante)
   - Duración recomendada: 2-5 minutos en loop
   - Volumen: Suave, no debe distraer
   - Estilo: Ambient, espacial, electrónico suave

2. **respiratory.mp3** - Narración del Sistema Respiratorio
   ```
   "El oxígeno entra y el dióxido de carbono sale. 
   El aire limpio es importante. 
   La nariz y los pulmones nos protegen del aire sucio."
   ```

3. **circulatory.mp3** - Narración del Sistema Circulatorio
   ```
   "El corazón bombea sangre con oxígeno. 
   El ejercicio acelera el corazón. 
   Podemos sentir el pulso en la muñeca."
   ```

4. **immune.mp3** - Narración del Sistema Inmunológico
   ```
   "El cuerpo tiene defensas. 
   Si vivimos mal, el cuerpo se debilita. 
   Comer bien y hacer ejercicio ayuda a defendernos."
   ```

## Herramientas Recomendadas para Generar Audio:

### Text-to-Speech en Español:
- **ElevenLabs** (https://elevenlabs.io/) - Voces naturales IA
- **Google Cloud TTS** (https://cloud.google.com/text-to-speech)
- **Amazon Polly** (https://aws.amazon.com/polly/)
- **Narakeet** (https://www.narakeet.com/) - Español latino

### Música Ambiental Gratuita:
- **FreePD** (https://freepd.com/)
- **Incompetech** (https://incompetech.com/music/)
- **YouTube Audio Library** (https://www.youtube.com/audiolibrary/)
- **Free Music Archive** (https://freemusicarchive.org/)

## Formatos Aceptados:
- MP3 (recomendado)
- OGG
- WAV

## Consejos:
- Mantén los archivos de narración entre 10-20 segundos
- La música ambiental debe ser sutil
- Usa voces claras y a velocidad moderada para educación
- Exporta en calidad media (128-192 kbps) para web
